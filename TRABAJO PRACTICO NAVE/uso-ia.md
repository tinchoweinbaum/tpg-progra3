Durante el desarrollo del proyecto se utilizó inteligencia artifical para la redacción de algunos contratos y consultas generales sobre la sintaxis y funcionalidades del lenguaje Java. Algunas partes de código fueron redactadas con inspiración en códigos hechos por IAs, pero, a menos que se aclare, no fue copiado tal cual fue provisto para no abusar de la herramienta y poder nosotros entender realmente el funcionamiento y el por qué de la utilización de dicho código

Todo el contenido generado con inteligencia artificial que se haya incluído en el proyecto fue previamente revisado y/o modificado por nosotros.
Se utilizaron unícamente modelos de LLM por navegador web, como Gemini y ChatGPT.

En la 2da entrega se utilizo inteligencia artifical para asistirnos con el uso de JDBC, especificamente la jerarquia de tipos del wrapper de Sqlite3 en JDBC. También, fue clave para la construcción y optimización de las vistas y el uso correcto de Java Swing
